# llm-d { #llm-d }

vLLM は [llm-d](https://github.com/llm-d/llm-d) と組み合わせてデプロイできます。llm-d は Kubernetes ネイティブの分散推論サービングのスタックで、大規模な生成 AI モデルを誰でもスケールさせてサービングできるよう、実績のある構成を提供します。主要な OSS モデルについて、多くのハードウェアアクセラレータやインフラ事業者の環境で、最短で最高水準 (SOTA) の性能に到達することを目指しています。

[公式ガイド](https://llm-d.ai/docs/guides)（英語）に従って直接使うか、[KServe の LLMInferenceService](https://kserve.github.io/website/docs/model-serving/generative-inference/llmisvc/llmisvc-overview) 経由で使えます。
