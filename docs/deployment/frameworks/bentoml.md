# BentoML { #bentoml }

[BentoML](https://github.com/bentoml/BentoML) を使うと、vLLM をバックエンドとする大規模言語モデル (LLM) のサーバーをデプロイし、OpenAI 互換のエンドポイントを公開できます。ローカルでサービングすることも、OCI 準拠のイメージにコンテナ化して Kubernetes にデプロイすることもできます。

詳細は [BentoML のドキュメントにある vLLM 推論のチュートリアル](https://docs.bentoml.com/en/latest/use-cases/large-language-models/vllm.html)（英語）を参照してください。
